Formal Guarantee Analysis & Verification

Proves or refutes scheduling-level guarantees over all static workloads bounded by max_tasks using Z3 SMT solving.

Formal Model Assumptions & Technical Scope

1. Workload Model: Single-CPU, non-preemptive CPU-bound tasks. Quanta and aging are discrete. Proof covers all workloads with 0 ≤ nj ≤ max_tasks and ni ≥ 1.
2. Wait Bound (from MODEL.md): Wi = Ai + H + BA where H = ∑(prioj < prioi) njQj, BA = ∑(agingj, prioj ≥ prioi) njQj − Qi. Starvation (Wi = ∞) if higher tiers exist without aging on class i.
3. Kernel Distinction: This verifier checks scheduling-level properties. It is not the Linux in-kernel eBPF register/memory safety verifier.
