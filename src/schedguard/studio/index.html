SchedLang Research Studio

An AI-Driven DSL Compiler for Adaptive eBPF Scheduling

SchedLang ensures AI-synthesized scheduling policies are safe by construction. An operator or AI agent writes policies in PolicyLang. The compiler lowers them to fixed-size IR, enforcible bounds are verified via static safety passes, and a Z3-based SMT verifier proves starvation freedom and CPU share bounds over all static workloads before simulation or eBPF code generation.

Formal Guarantee Analysis & Verification

Proves or refutes scheduling-level guarantees over all static workloads bounded by max_tasks using Z3 SMT solving.

Formal Model Assumptions & Technical Scope

1. Workload Model: Single-CPU, non-preemptive static CPU-bound tasks. Quanta and aging are discrete. Proof covers all workloads $0 \le n_j \le \text{max\_tasks}$ with $n_i \ge 1$.
2. Analyzer Type: Custom SMT scheduler analyzer implemented in Z3 over linear integer arithmetic. Refutations are cross-checked via concrete discrete simulation replay.
3. Kernel Distinction: This scheduling verifier is not the Linux in-kernel BPF verifier (which verifies load-time register/memory safety). Real-kernel behavior remains untested until Phase 4 live loading.
